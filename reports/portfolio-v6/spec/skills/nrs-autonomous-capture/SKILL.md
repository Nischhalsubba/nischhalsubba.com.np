# Autonomous capture
Load 01_MASTER_CODEX_PROMPT.md and sitewide discovery guide. Inspect repository sources and current built-site DOM; enumerate **all** media content placements, not only 41 blog/project heroes. Find source pages/subroutes and suitable product states per placement, rather than using any fixed screenshot filenames or owner uploads as final defaults. For sites: use Playwright/browser if installed, desktop/mobile, wait for fonts and image decode, traverse meaningful pages, consented UI states and capture real frames. For Figma: export authenticated original frames/nodes if connected and allowed; do not invent authorship. For local project build: run and capture the genuine interface. Save immutable original PNGs and machine-readable capture manifest (URL/Figma node/commit, UTC, viewport, HTTP/browser state, SHA256, role/rights). Reject broken, private, unrelated, or only decorative images; block and document if source inaccessible. Original source images must be kept independent of derivatives. Never automatically crawl restricted sites, scrape private accounts or bypass login. Generated screenshots may become static local site assets after editorial selection; this is correct and is NOT forbidden 'hardcoding'.
