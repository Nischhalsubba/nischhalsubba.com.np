# Social Identity and Uxcel Verification

Apply for T99–T107 and existing profile-proof tasks as relevant. Before changing a public site or asserting a credential, read `references/SOCIAL_AND_UXCEL_SOURCE_AUDIT_v5_3.md` and `ledgers/SOCIAL_PROFILE_VERIFICATION.csv`.

1. Fetch the user-provided Linktree directory with real browser automation. Enumerate the actual clickable destination for every professional and social icon. Record platform, exact destination/redirect, handle, public title, status, date and screenshot; text labels alone do NOT verify a profile URL.
2. Verify owner identity against reciprocating links or source records; distinguish public professional profiles from personal/inactive accounts, never publish personal WhatsApp/Snapchat/email by default.
3. Inspect the specific Uxcel profile. Independently verify certificates, badge graphics, course completions, skill assessment scores and issued dates. Public Uxcel Hall of Fame confirms a 2023 Product Designer listing; the exact rank is not verified by this single listing. Current live Uxcel weekly rank and score change over time. Do not invent or preserve unverified rank claims.
4. Maintain one source-of-truth registry for approved public professional links. Populate `Person.sameAs` only with authenticated owner-controlled public identities. Test built HTML schema, metadata and author references.
5. Display authentic issuer badges in the existing portfolio visual language, with names, year, role/category, evidence link, permission and alt text. No AI-generated or stylized fake official certificates.
6. Update key website links (About, contact, footer, credentials, home when appropriate) without making every platform a nav item. Use accessible icon names, logical focus, mobile checks and reputable link destinations.
7. Treat edits on LinkedIn/Linktree/Uxcel/social apps as owner-controlled external actions. The portfolio release cannot truthfully claim to have changed external bios without authorized tools and reported results.
8. Save a verification report and source inventory. `VERIFIED_SOURCE`, `NEEDS_OWNER_CONFIRMATION`, `AUTH_BLOCKED`, `INACTIVE_PROFILE`, `PENDING_PUBLICATION`, `PUBLISHED_AND_TESTED` are valid states. Never report 100% if authenticated UI is unavailable.
