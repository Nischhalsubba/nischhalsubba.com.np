# Blog and case-study editorial voice
1. Read `references/BLOG_AND_CASE_WRITING_VOICE_v5.md`, actual website source, owned Figma screen selection and source project, then official Google people-first content.
2. Bishal reference is **Medium @bishaller**, not an independently verified blog at bishal.cc. Extract structural principles: clear hook, authentic first-person insight, specific tension, concrete example, honest lesson, concise takeaway. Do not copy sentences or mimic personal experiences you did not have.
3. Niraj `nirajs.com.np` examples are **case studies**, not proof of a blog. Extract grounded organization: context -> problem -> research if verified -> decisions -> solution evidence -> limitations/outcome.
4. Every article requires a distinct target reader, question, original example, project/source-linked genuine image and 1 useful link to appropriate case/service. Variation in word count is acceptable. No SEO jargon exposed to visitors, no LLM self-reference, no generic conclusions, no imagined anecdotes, dates or metrics.
5. Critically review 27 canonical articles before any rewrites; compare raw sources, generated pages and live served output. Draft-only blog files remain unpublished unless explicitly authorized.
6. Existing project contribution must be consistent with CV and original source. When results are not known, state observable artifact/process, not invented KPIs.
7. Return per-page before/after editorial diff, sources, article intent, acceptance notes and measured change after publication.
