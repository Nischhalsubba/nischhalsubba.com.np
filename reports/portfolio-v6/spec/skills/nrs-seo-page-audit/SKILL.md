# nrs-seo-page-audit

Use the route manifest, inspect source and generated output, then test production only when accessible. Each route: HTTP status, indexable robots, canonical and redirects, title uniqueness/context, useful description, one meaningful H1, headings, visible text, OG/Twitter previews, image metadata, JSON-LD validity, breadcrumbs, internal links, content and semantic links. Verify Schema.org type and that every schema claim is visible and true. Check URL HTML files vs clean canonical, host and sitemap reconciliation, no duplicate index pages. Avoid keyword stuffing, mechanical length targets and artificial FAQ markup. Use Google's SEO Starter Guide, Image SEO, structured-data and Google AI guidance. Output row-level evidence and severity.

## Deliverables
Write evidence-backed changes or an audit record, including paths, date, validation command/output, actual blockers and clear follow-ups.
