# nrs-ux-a11y

Preserve approved workspace/toolbar visual language and blog icon/breadcrumb system. Test 320/375/390/768/1024/1440/1920 layouts; 200/400% text zoom spot checks; contrast; visible focus; skip link; one breadcrumb; menus; project cards; contact form; image lightboxes; reduced-motion; no-JS content; screen-reader manual review where possible. Automated axe passes do not equal WCAG compliance. Record issue with exact route, reproduction, screenshot, WCAG criterion, fix and test. Avoid generic redesigns; preserve full-screen asset readability.

## Deliverables
Write evidence-backed changes or an audit record, including paths, date, validation command/output, actual blockers and clear follow-ups.
