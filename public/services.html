Process

A simple way to reduce product fog.

The point is not to make more screens. The point is to make better decisions before those screens become someone else's engineering problem.

01

Audit the product context

Understand users, business goals, current friction, flows, content, data and technical constraints.

02

Structure the experience

Define page hierarchy, screen flow, navigation, states, labels and the decisions users need to make.

03

Design the interface

Create polished UI using reusable patterns, responsive rules, component states and practical interaction behavior.

04

Prepare handoff

Document edge cases, QA notes, implementation priorities and Figma context so the work survives development.
