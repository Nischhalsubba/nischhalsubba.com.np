# Job Finder — Website UI Design

## Project overview

Job Finder is a website design project published in June 2021. My portfolio identifies my roles as Graphic Designer and Product Designer, with Figma and Adobe Photoshop as the tools used. The original Instagram publication remains the primary source for this project.

## Design context

The project belongs to the job-discovery website category. In this context, a useful interface needs to help people understand available opportunities, compare relevant information and identify the next step toward applying. These are retrospective design considerations, not a claim that particular features were present in the original design.

## Contribution and deliverable

The documented deliverable is website design. My recorded roles cover product and graphic design. ## Proposed evaluation

If revisiting this work, I would assess whether a visitor can locate relevant opportunities, interpret job information, understand filtering and navigate to an application route. I would also check keyboard accessibility, responsive layout, empty and error states, and the clarity of calls to action. These are proposed evaluation tasks rather than completed research or verified findings.
