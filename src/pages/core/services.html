Working process

Four stages. Each one removes a different kind of uncertainty.

  1. 01

    Context

    Users, business goal, constraints, evidence and current friction.

  2. 02

    Structure

    Journeys, hierarchy, content priority, states and decision points.

  3. 03

    Interface

    Reusable patterns, responsive screens and reviewable prototypes.

  4. 04

    Handoff

    Behavior notes, assets, edge cases, responsive rules and UI QA.
