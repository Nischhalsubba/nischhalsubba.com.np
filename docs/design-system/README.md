# Design system documentation

This folder documents the portfolio's visual and interaction system.

- `master.md` is the design-system master reference formerly stored as `MASTER.md` at repository root.
- Production CSS lives in `src/styles/style.css`.
- Design-system coverage is checked by `scripts/audit-design-system-coverage.cjs` and related accessibility audits.

Documentation describes intent; production source and automated audits remain the implementation authority.
