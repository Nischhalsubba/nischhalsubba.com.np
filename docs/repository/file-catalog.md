# Tracked File Catalog

> Generated by `scripts/repository/generate-file-catalog.cjs`. Do not maintain catalog rows by hand.

The repository structure changed during the current cleanup, so the previous generated inventory was intentionally cleared rather than leaving stale filenames and ownership notes in source control.

Regenerate the complete catalog from the tracked Git tree with:

```bash
npm run docs:file-catalog
```

The full validation workflow runs this generator before repository-structure audits:

```bash
npm run validate
```

For the human-maintained architecture and ownership model, see `docs/repository/file-map.md`.
